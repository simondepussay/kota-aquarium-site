# こた水族館 — KOTA AQUARIUM

イラストレーター「こた」のWebサイト（HAL東京のコンテスト作品）
*Website for the Japanese illustrator こた (Kota), made for a HAL Tokyo contest.*

**公開サイト / Live site:** https://gray-cliff-055dc5d00.5.azurestaticapps.net/

## 内容 / What's inside

- HTML / CSS / JavaScript（フレームワークなし / no framework）
- 夜モード、泡のアニメーション、スクロールで現れる要素 / night mode, bubble animations, elements that appear on scroll
- パソコン・スマートフォン対応 / responsive, desktop and smartphone
- Azure Static Web Apps でホスティング / hosted on Azure Static Web Apps

## 画像について / About the images

イラストはすべて こた さんの作品のため、このリポジトリには含めていません。サイトの見た目は公開サイトでご覧ください。

*All illustrations belong to こた and are not included in this repository. See the live site for the full design.*
